# quantseq-counts

Gene counts, a quality report and a full record of the run from Lexogen QuantSeq 3' mRNA-Seq FWD libraries (with
or without UMI), on a shared server without administrator rights, with counts that are identical on every rerun.

**Status: under development. There is no release yet; do not use it for analyses.**
